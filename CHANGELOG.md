# Changelog

All notable changes to ScreenCatch are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-28

### Added

- Region capture over a frozen screen with resize handles, keyboard nudging and a live pixel size readout.
- Quick actions straight from the selection: open the editor, copy, or save.
- Annotation editor with arrow, rectangle, ellipse, line, pen, highlighter, text, numbered step,
  pixelate and crop tools; Shift constrains shapes.
- Select, move, recolor, resize and delete annotations; unlimited undo and redo.
- Copy to clipboard (kept available after the editor closes) and PNG saving with configurable folder
  and file name template.
- Whole-screen and delayed capture, and opening existing PNG/JPEG images.
- Automatic Ctrl+Shift+Print global shortcut on GNOME, configurable in Preferences.
- Debian package, man page, AppStream metadata and desktop actions.
